# VSM Female - 1.0.8 is out!

:exclamation: Remember to repair your mod :exclamation:

**What's fixed**
- **Gender switch in limited arsenals** - with ACE Arsenal Extended, the "Gender" option offered the female version even when the arsenal only holds the original. That item wasn't part of the arsenal, so it vanished after leaving and saved loadouts showed it as missing. The switch now only offers what the arsenal actually has

Your class names stay the same, nothing else changed.

All credit for the original gear goes to the VSM team: VSM, VanSchmoozin, Roadrunner, Spectre, Zeealex, Jarrad96, CrazyCorky, Bacon and Ghost :blue_heart:
