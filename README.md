# VSM Female

Female vests and uniforms for VSM. **VSM is the main mod, this is only an add-on for it.**

206 vests and 361 uniforms, in every camo, with the same stats. The male items stay untouched.

## Requires

[VSM All-In-One Collection](https://steamcommunity.com/sharedfiles/filedetails/?id=823636749) for all 567 items, or [VSM Uniforms](https://steamcommunity.com/sharedfiles/filedetails/?id=1452762519) and/or [VSM Vests and Helmets](https://steamcommunity.com/sharedfiles/filedetails/?id=1456022305) for their 453 items, on the server and every client.

Works with [ACE3 Arsenal Extended](https://steamcommunity.com/sharedfiles/filedetails/?id=2522638637) and its compat mods (not required): the "Gender" option swaps an item between the original and the female version. Without ACEAX, female items are their own Arsenal entries.
